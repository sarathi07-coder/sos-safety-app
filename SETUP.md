Add this content to `.env`:
```

TWILIO_ACCOUNT_SID=your_twilio_sid_here
```

## 🔑 STEP 5 — Get API Keys

You need accounts and API keys for these services:

### 5.1 — SMS for SOS Alerts (FREE Options — NO Twilio needed)

> ❌ Twilio is NOT free — it charges per SMS. Use these instead:

---

#### ✅ Option A — Native Android SMS (BEST — 100% Free)

Uses the **user's own SIM card** to send SMS directly from the phone.
- No API, no cost, no account needed
- Works offline (no internet required)
- Uses `telephony` Flutter package

```bash
# Add to pubspec.yaml
telephony: ^0.2.0
```

How it works:
```dart
final Telephony telephony = Telephony.instance;
await telephony.sendSms(
  to: "+91xxxxxxxxxx",
  message: "🆘 SOS! [Name] needs help. Location: https://maps.google.com/?q=lat,lon"
);
```
> ✅ No monthly cost. Uses phone's own carrier SMS.

---

#### ✅ Option B — Fast2SMS (Cheapest Indian API — ₹0.20/SMS)

1. Go to: https://www.fast2sms.com
2. Sign up → free ₹50 credit on signup (250 free SMS for testing)
3. Get your API key from dashboard
4. Add to `.env`:
```
FAST2SMS_API_KEY=your_key_here
```

How to send:
```js
// backend/services/sms_service.js
await axios.get('https://www.fast2sms.com/dev/bulkV2', {
  params: {
    authorization: process.env.FAST2SMS_API_KEY,
    numbers: '9xxxxxxxxx',
    message: '🆘 SOS Alert from AlleyPilot!',
    route: 'q'
  }
});
```
> ✅ Recommended for production. ₹200 = 1000 SMS.

---

#### ✅ Option C — MSG91 (Enterprise Indian SMS)

1. Go to: https://msg91.com
2. Free trial: 25 SMS on signup
3. Cheapest plan: ₹299/month for 1000 SMS
> Use this only if you need transactional SMS with templates.

---

#### ⭐ Recommended Strategy:

| Scenario | Use |
|----------|-----|
| Testing / Development | Native Android SMS (free) |
| Production (India users) | Fast2SMS API (₹0.20/SMS) |
| International users | MSG91 or AWS SNS |

### 5.2 — Calling Features Plan

AlleyPilot has **3 different call-related features**. Here's how each works:

---

#### 📞 Call Feature 1 — Fake Incoming Call (Decoy Call)

**Purpose:** User in danger can make it look like someone is calling them to excuse themselves.

**How it works:**
- User taps "Fake Call" button
- App shows a **full-screen fake incoming call UI** (looks exactly like Android default call screen)
- Shows a custom name + number (user pre-sets it: e.g. "Mom")
- Phone vibrates like a real call
- User "answers" → app plays a **pre-recorded voice audio** (sounds like a real conversation)
- Attacker sees person is on call → backs off

**Tech used:**
```yaml
# Already in pubspec.yaml
flutter_phone_direct_caller: ^2.1.1
audioplayers: ^5.2.1  # Play pre-recorded voice
```

```dart
// Show fake call overlay
Navigator.push(context, MaterialPageRoute(
  builder: (_) => FakeCallScreen(callerName: "Mom", callerNumber: "+91 98765 43210")
));
// FakeCallScreen is a custom full-screen widget that mimics Android call UI
```

---

#### 📞 Call Feature 2 — Auto-Call Guardian on SOS

**Purpose:** When SOS is triggered, app automatically calls the primary emergency contact.

**How it works:**
- SOS button pressed → after SMS is sent → app auto-dials the #1 emergency contact
- Uses native Android call (no VoIP needed, uses user's own carrier)
- Guardian picks up → hears user directly (or hears ambient sound if user can't talk)

**Tech used:**
```dart
import 'package:flutter_phone_direct_caller/flutter_phone_direct_caller.dart';

// Auto-call emergency contact
await FlutterPhoneDirectCaller.callNumber("+91xxxxxxxxxx");
```

> ✅ 100% Free — uses phone's own SIM calling

---

#### 📞 Call Feature 3 — Voice TTS Location Read (No Internet Call)

**Purpose:** When user has NO internet but CAN make a call — app reads out GPS coordinates via Text-to-Speech during a call.

**How it works:**
- User is on a call with guardian (manually or auto-dialed)
- App uses TTS to speak: *"Current location: Latitude 12.9716, Longitude 77.5946. Nearest landmark: MG Road, Bengaluru"*
- Guardian hears this and can locate user even without internet

**Tech used:**
```yaml
flutter_tts: ^4.0.2  # Add this to pubspec.yaml
```

```dart
FlutterTts flutterTts = FlutterTts();
await flutterTts.speak(
  "SOS! Current location is Latitude $lat, Longitude $lon. Please come immediately."
);
```

---

#### Summary — All Calling Features

| Feature | Cost | Tech | When Used |
|---------|------|------|-----------|
| Fake Incoming Call | FREE | Custom Flutter UI + audioplayers | User in danger, needs excuse |
| Auto-call Guardian | FREE | flutter_phone_direct_caller (native) | SOS button pressed |
| Voice TTS Location | FREE | flutter_tts | No internet, but on a call |

## ❓ Common Errors and Fixes

| Error | Fix |
|-------|-----|
| `flutter: command not found` | Add Flutter to PATH: `export PATH="$PATH:/path/to/flutter/bin"` |
| `No connected devices` | Enable Developer Mode on Android phone OR start emulator |
| `Firebase not initialized` | Make sure `Firebase.initializeApp()` is called in `main.dart` |
| `Twilio SMS not sending` | Check .env has correct SID, Token, and phone number format (+91...) |
| `Permission denied on Android` | Add permission to AndroidManifest.xml AND request at runtime |
| `Port 3000 already in use` | `lsof -i :3000` then `kill -9 <PID>` |
| `flutter pub get fails` | Check internet connection + correct pubspec.yaml indentation |
